Hello!

Thank you for downloading Desktop Block.

Desktop Block is a friendly desktop companion
made by Team Ruby.

Desktop Block can:

- Talk
- Sleep
- Jump Around
- Remember A Name
- Display Speech Bubbles
- Keep You Company

=========================================
INSTALLATION
=========================================

1. Extract the ZIP file.
2. Open the extracted folder.
3. Run DesktopBlock.exe

Desktop Block should now appear on your desktop.

=========================================
NAME MEMORY
=========================================

Desktop Block may tell you that he has
forgotten his name.

You can use the "Name Me" option to help
Desktop Block remember a name.

Desktop Block will save that name and
remember it the next time the application
is launched.
